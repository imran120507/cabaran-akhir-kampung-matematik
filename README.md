# Cabaran Akhir — Kampung Matematik

Permainan interaktif Matematik Tahun 5: luas bentuk gabungan.

## Terbitkan melalui GitHub Pages
1. Cipta repository awam baharu, contohnya `cabaran-akhir-kampung-matematik`.
2. Muat naik fail `index.html` ini ke bahagian root repository (bukan dalam folder lain).
3. Pergi ke Settings > Pages.
4. Di Build and deployment, pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Selepas diterbitkan, URL lazimnya: `https://USERNAME.github.io/cabaran-akhir-kampung-matematik/`.
6. Dalam Google Sites: Insert > Embed > By URL, tampal URL GitHub Pages dan terbitkan laman.

Nota: GitHub Pages ialah hos laman statik. Markah XP hanya wujud dalam sesi pelayar dan tidak disimpan sebagai rekod rasmi. Tiada butang cetak sijil.
